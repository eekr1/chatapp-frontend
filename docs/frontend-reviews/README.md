# TalkX Frontend Görsel İncelemeleri

Bu klasör deploy sonrası frontend görsel incelemelerinin kalıcı evidir.

## Kullanım

1. [`../templates/FRONTEND_VISUAL_REVIEW_TEMPLATE.md`](../templates/FRONTEND_VISUAL_REVIEW_TEMPLATE.md) dosyasını tarihli yeni bir klasöre kopyala.
2. İnceleme görsellerini aynı klasördeki `frontend-visual-review-assets/` dizinine koy.
3. Her bulguyu benzersiz kimlik, öncelik, kapsam, kanıt, karar ve kabul kriterleriyle kaydet.
4. Uygulama tamamlanınca otomatik doğrulamaları ve manuel kapanış checklist'ini işle.
5. Ürün dışı veya backend bağımlı işleri ayrı başlıkta açık bırak.
